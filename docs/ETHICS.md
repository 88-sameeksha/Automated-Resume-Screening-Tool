# Responsible use

This is an educational demonstration using synthetic resumes. The relevance score
is a rough text-matching signal, not a measure of a person's ability, potential,
character, or suitability for employment.

Do not use this starter project to make or automate real hiring, rejection,
promotion, or other consequential employment decisions. Do not add or infer
protected or sensitive attributes. Keep a human reviewer responsible for
interpreting evidence, checking context, and considering applicants fairly.

Keyword matching can miss synonyms, equivalent experience, formatting variations,
and skills expressed in different ways. TF-IDF measures text overlap, not truth
or competence. Validate any real-world system with appropriate legal, privacy,
security, accessibility, and bias reviews before considering deployment.
